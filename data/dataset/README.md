# Final Dataset

This folder stores the final per-protein dataset artifacts generated by
`scripts/13_final_dataset.jl`.

## Artifacts

- `data/dataset/cluster_dataset_labels.csv.gz`
- `data/dataset/cluster_dataset_labels.json.gz`

Both files contain the same proteins and split labels. The JSON keeps
`residue_labels` as integer vectors, while the CSV stores `residue_labels` as a
compact string with one character per residue (`0`, `1`, `2`).

## Data Dictionary (Added Final Columns)

- `protein_elm_clusters`: one or more ELM motif-cluster IDs for each protein,
  joined by `-` when multiple clusters are present.
- `cluster_dataset_label`: final split label constrained to `training`,
  `validation`, and `testing`; values are derived from
  `cluster_fixed_dataset_label` by keeping `training`, mapping `caid` to
  `testing`, and assigning missing values to `validation` (default).
- `sequence`: full protein sequence from DisProt.
- `residue_labels` (JSON): per-residue integer vector with
  `0 = ordered`, `1 = disordered`, `2 = binding`.
- `residue_labels` (CSV): string encoding of the same labels, one character per
  residue.

## Source Inputs

- `data/derived/fixed/cluster_fixed_labels.csv.gz`
- `data/derived/elm/elm_motif_clustering.csv.gz`
- `data/raw/disprot/disprot_regions.json.gz`

## Reproducibility

Run from repository root:

```bash
julia scripts/13_final_dataset.jl
```

Complete example:

```bash
julia scripts/13_final_dataset.jl --fixed_labels_path data/derived/fixed/cluster_fixed_labels.csv.gz --elm_motif_clustering_path data/derived/elm/elm_motif_clustering.csv.gz --raw_data_dir data/raw --output_dir data/dataset --output_csv_filename cluster_dataset_labels.csv.gz --output_json_filename cluster_dataset_labels.json.gz --missing_label validation
```

## Backup Check

To verify the generated JSON matches the preserved backup artifact:

```bash
cmp data/dataset/cluster_dataset_labels.json.gz backups/cluster_dataset_labels.json.gz
```
