IDRBindingDataset._build_all_vs_all_blastp_args — Method
_build_all_vs_all_blastp_args(input_fasta_path, db_prefix, blast_output_path; threads)

Build DIAMOND blastp arguments for all-vs-all local homology discovery.

Parameter rationale:

  • --evalue 1000: keep search permissive; final inclusion is controlled by explicit Julia-side thresholds (identity, coverage, ungapped length).
  • --max-target-seqs 0: keep all candidate neighbors for graph edges.
  • --max-hsps 0: keep alternative local alignments (needed for local homology).
  • --no-self-hits: suppress trivial self alignments.
  • --ultra-sensitive: maximize sensitivity for local hit discovery.

Add a cutoff-based label for clusters with missing fixed labels.

  • protein_oldest_disprot_release_date

Returned table includes all input columns plus:

  • cluster_min_protein_oldest_disprot_release_date

Rules:

  • Keep existing cluster_fixed_dataset_label values (training, caid) unchanged.

    • otherwise assign training.
